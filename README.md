# clockout

一个常驻 macOS 的三级工作容量助手：最小倒计时、6×6任务棋盘和完整排期工作台。

## 当前技术形态

- React + TypeScript + Vite 前端
- Electron 无边框透明桌面壳
- Electron 主进程使用 Node 内置 `node:sqlite` 持久化任务，数据库位于 `~/Library/Application Support/clockout/clockout.sqlite`
- 本机尚未安装 Rust/Cargo，因此暂时没有切换到 Tauri；前端与桌面桥接已分层，安装 Rust 后可以把 Electron 桥替换为 Tauri commands
- 根目录 `index.html` 是每次构建同步生成的网页 Demo，可直接打开

## 运行

```bash
npm install
npm start
```

质量检查：

```bash
npm run check
```

## 三级窗口

- 启动后显示 `228 × 60` 最小倒计时
- 展开为 `520 × 320` 任务棋盘：6×6棋盘、倒计时、今日工资和额外补偿
- 再展开为 `1040 × 720` 详细工作台：任务顺序、拖拽排期、明日任务、工时与工资
- 可从详细工作台或状态栏菜单打开独立的「管理后台」网页：添加、编辑、分配、筛选、更新状态和删除任务
- 三种尺寸都有自绘的尺寸切换和退出按钮；退出会真正结束应用
- 顶部状态栏仍作为备用入口
- 状态栏直接显示原创办公图标和实时下班倒计时
- 为避免被刘海和其他状态项挤走，状态栏使用精简的 `HH:MM`，展开后显示到秒
- 单击状态栏项目：显示或隐藏最小倒计时
- 右键状态栏项目：打开任务棋盘、详细界面、管理后台网页或退出应用

## 管理后台

- 管理后台是独立网页 `admin.html`，由 clockout 本机服务提供页面和任务 API
- 管理后台与员工工作台共用同一份 SQLite 任务数据，新增任务后会立即进入员工排期
- 老板可以连续添加多项待确认任务；点击「确认发送」后，这一批任务才会发送到员工工作台
- 每日确认后继续新增的任务会保持待确认状态；发送前需要确认并记录超额费用，费用按 60 元/小时和 1.5 倍加班倍率计算
- 支持负责人、优先级、安排日期、截止时间、任务类型、状态和锁定时间管理
- 支持按任务名称或负责人搜索，并按日期和状态筛选
- 今天的容量、待处理数量和进行中数量会在后台顶部实时汇总
- 当前网页服务只监听本机回环地址，不是对外开放的网络管理站点；网页 Demo 继续使用 localStorage 预览

## 任务规则

- 蓝色：普通任务
- 黄色：会议沟通
- 绿色：AI 可协助
- 红色：紧急任务
- 灰色：等待审批
- 紫红色：老板临时任务

任务完成后才从棋盘消失，不会因为填满一行而自动消除。老板任务导致加班时会停在棋盘上方，必须选择替换、延期、缩小范围、转交或增加补偿后才能进入。

## 稳定排期规则

- 棋盘严格按照从左到右、从上到下的36个时间槽排布，不再使用蛇形路线
- 数据以完整任务保存，`durationSlots` 决定连续占格数量，不保存格子的CSS坐标
- 拖动超过5px才开始，拖动时只更新预览，松手后一次提交
- 放到目标任务前后采用插入排序，后续任务整体顺延且不会覆盖
- 过去时段、进行中任务与锁定任务不能移动，柔性任务自动绕开锁定时间
- 超出18:00后必须选择延后、缩短、替换、确认加班或取消
- 明日任务可以拖回今天；所有正式调整提供5秒撤销和 `Command/Ctrl + Z`
